# Local native-source evidence and public publication boundary

The original saved-workspace source reads were reference evidence for the owner's
local project. No permission to redistribute those third-party script bodies has
been documented. During the 2026-10-12 public migration, 38 raw `.source.txt` files
(178,725 bytes) were excluded from Git publication. They remain in the original
local directory and in the verified external recovery backup; none were deleted.

`AntiAFK_KEY_SEARCH.source.txt` is an authored search log and summary rather than
a raw script body, so it is included. `COMMON_EGG_PROMPT_GEOMETRY.json` and
`MYSTERY_GIFT_RECHECK.md` are also included as observations and authored analysis.

The excluded original file names, native paths and SHA-256 values remain recorded
in [LOCAL_FEATURES_DELIVERY.json](../LOCAL_FEATURES_DELIVERY.json). Source citations
in [LOCAL_FEATURES_STUDIO_RECHECK.md](../LOCAL_FEATURES_STUDIO_RECHECK.md) identify
the original local evidence and line ranges; their raw-file links are available
in the local project/recovery copy, and do not promise public access.

Both completed research libraries are included unchanged. Their attributed
summaries, factual catalogs, metadata, observations, limitations and source
ledgers remain usable without republishing the game scripts.
