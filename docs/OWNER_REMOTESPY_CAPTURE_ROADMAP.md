## 1. Purpose and Evidence Rules

Use this guide during normal owner gameplay to collect the smallest observation that makes an action implementable or verifies a real result. It inventories the important gameplay requests documented in the completed libraries, including metadata-only interfaces whose arguments remain unknown. It does not claim every saved script has a complete action contract or that the saved game matches every current live server.

Evidence order: owner-observed received results → reviewed native ReplicatedStorage behavior → tested OC implementation → saved research/ledgers → wiki strategy. ReplicatedStorage supplies definitions and interfaces; verified `LocalData:Get()` supplies received account facts; Workspace supplies current objects, geometry and arrival/interaction state. Server handlers remain unavailable. A sent request, truthy return, animation, closed menu or scheduler `COMPLETED` status alone never proves delivery.

## 16. Unknowns RemoteSpy Cannot Resolve

RemoteSpy can expose ordered client requests and, depending on its functionality, RPC returns/incoming notifications. It cannot independently establish:

- Server acceptance, hidden distance/access/rate validation, authoritative price/grant/odds, rollback or safe retry after timeout.
- Current account eligibility when received required fields are missing; native auto capability absence from a quiet request log; complete wheel queue idleness.
- Inventory/currency receipt, net versus gross grant, canonical item schema, protection state, or excluded passive/external gains without received account evidence.
- Safe standing/clearance, native interaction volume, streamed object identity, actual arrival, Rift availability/expiry or legitimate checkpoint traversal without live Workspace/UI observations.
- Rejoin saving/persistence, account durability or claim ledger persistence beyond the actual implemented runtime.
- Rare pet/variant odds from a short sample; exact return/time or Mastery multiplier effectiveness from a description; obsolete event availability from retained catalogs.
- Meaning of metadata-only labels/arguments, damaged decompiled locals or absent server handlers. Only a specific relevant source/normal observation gap should trigger further research.

Use the backlog's alternative: fresh minimal LocalData schema/deltas, native UI/FSM, actual Workspace object/range/arrival, naturally occurring rejoin, or a separately approved bounded live receipt. Do not substitute arbitrary replay, extra paid trials or research loops.
